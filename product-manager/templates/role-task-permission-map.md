# Role × Task × Permission Map｜角色任务权限地图

> 本次要支持的决策与目标角色：

| 角色 | 高频任务与触发场景 | 可读对象 | 可写/审批动作 | 禁止动作 | 结果给谁看 | 失败/撤权处理 | 证据 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

## 关键任务闭环

入口 → 选择/录入 → 提交 → 系统反馈 → 对端可见结果 → 重试/纠错/撤销。

## 权限验收

- 本人、本班、跨班、离职/停用、角色变更分别能看到和操作什么？
- 拒绝访问时是否无数据泄露，并给出可理解的下一步？
- 权限是在 UI 和服务端都执行，还是只在一处显示？`[待验证]` 时不得视为通过。
