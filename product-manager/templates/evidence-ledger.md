# Evidence Ledger

只记录会影响产品决定的关键主张；原始材料仍留在其原位置。每条观察使用稳定 ID，范围或来源改变时新增条目，不覆盖旧观察。`USABLE` 仅指在所列范围和观察日期内可使用，不保证今天仍成立。

## EV-YYYYMMDD-01 — 简短主张

- Claim: 可被核验的一句话；不要把建议写成事实
- Class: SOURCE-FACT / INFERENCE / HYPOTHESIS
- Source / locator: 原始文件及章节/行、匿名访谈 ID、指标查询与口径，或具体网页；无法定位填 `[待验证]`
- Observed at / accessed at: YYYY-MM-DD；区分事件发生日与资料访问日
- Applies to: 产品版本 / 环境 / 用户群 / 地区 / 时间窗口
- Evidence quality / limits: 一手或二手、样本/偏差/缺失、已知限制；不填无依据的精确置信度
- State: USABLE / NEEDS-RECHECK / CONTESTED / SUPERSEDED
- Recheck trigger: 何时或什么变化会使它需要重查
- Conflicts with / superseded by: 相关证据 ID；无则填 none
- Used by decision: 决策 ID；尚未用于决策可填 none

示例中的占位值不可当成实际证据。材料若含个人资料或商业秘密，只保存最小定位信息与脱敏摘要；不要复制完整访谈、日志或受限内容。仅在项目记录的写入已获授权时保存，否则把所需条目作为回复草稿。
