# Skill Badcase｜私有工作记录模板

> 放在使用者明确指定的 Skill 包外目录。公开仓库只可收录经过授权审查的脱敏/合成复现，不收录客户原文或凭证。未知项写 `[待验证]`，不要补造。

## 身份与来源

- Case ID / 日期 / Owner：
- 任务与目标模式：
- Skill 版本 / 模型 / 工具及环境：
- 原始证据位置、访问限制、保留期限：
- 使用与二次利用权限：`已确认 / 待确认 / 不允许`；依据：
- 脱敏状态：`未处理 / 已脱敏 / 合成`；公开可用：`是 / 否 / 待审`：

## 失败事实

- 当时可用的信息和用户意图（最小必要摘要）：
- 期望的可观察行为：
- 实际行为（引用受限证据位置，不粘贴敏感原文）：
- 实际/潜在影响、严重度与发生频率：
- 复现条件与不确定性：

## 归因与处理

- 主因候选：`规则/路由 | 知识时效 | 模板/工具 | 模型波动 | 输入/上下文 | 外部执行 | 未定`
- 支持证据 / 替代解释 / 置信度：
- 非 Skill 的责任方或下一动作（如适用）：
- 状态：`NEW | TRIAGED | PROPOSED | VERIFIED | CLOSED`
- 本轮决定、Owner、下次复查触发条件：
