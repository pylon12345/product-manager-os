- [ ] PRD / AI PRD 状态 Ready
- [ ] Acceptance Criteria 全通过

- [ ] Analytics events 已验证
- [ ] Dashboard / alert 已可用
- [ ] Feature Flag / Kill Switch
- [ ] Rollback / fallback 已验证
- [ ] 权限 / 隐私 / 数据保留确认
- [ ] Support Owner / FAQ / escalation path
- [ ] 依赖 / quota / rate limit 检查
- [ ] AI Eval Gate 通过（适用时）
- [ ] 成本与延迟在预算内（适用时）
- [ ] Badcase 回收路径可用（适用时）
