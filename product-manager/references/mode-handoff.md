# Mode: handoff

研发交接的目标是让工程和测试知道“什么算对”，而不是替工程规定内部实现。

至少包含：
- 背景 / Goal / Non-goal
- User Flow
- Functional Rules
- State & Edge Cases
- 信息优先级、完成反馈、恢复动作与可用性验收（适用时）
- Data / Permission / Privacy
- Dependencies
- Acceptance Criteria
- Analytics events
- Rollout / Feature Flag / Rollback

AI 需求额外引用 AI PRD 与 Eval Spec。
模板：`templates/tech-handoff.md`。
