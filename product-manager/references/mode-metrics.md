# Mode: metrics

## 指标层级
1. **Outcome / North Star**：用户真正获得价值的结果。
2. **Input Metrics**：驱动结果的行为。
3. **Funnel**：访问 → 激活 → 核心价值 → 留存/复用 → 付费。
4. **Guardrails**：投诉、错误、成本、延迟、安全等不能恶化的指标。
5. **Counter-metrics**：防止通过作弊方式优化主指标。

每个关键指标写：定义、事件口径、基准、目标、观察窗口、Owner/数据源。未知则写 `TBD`。

诊断指标变化前，先确认埋点与定义是否变化。
