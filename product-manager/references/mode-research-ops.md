# Mode: research-ops

目标：让用户研究从“做访谈”变成可追溯、可复用、能改变决策的证据系统。

## 1. Research Brief

- 要支持的决策、Owner、Deadline
- Research questions，不写希望证明的答案
- Target population 与明确排除人群
- 已有证据、关键未知、方法限制
- 招募、激励、同意、录音、隐私和保留策略
- 停止条件与“学够了”的判定

## 2. 方法选择

| 目的 | 优先方法 | 不可得出的结论 |
|---|---|---|
| 理解行为和情境 | 情境访谈、JTBD、日记、观察 | 市场比例 |
| 发现可用性问题 | 任务式可用性测试 | 购买意愿 |
| 判断普遍性 | 调研/行为分析，建立在定性发现后 | 深层机制 |
| 分析流失和切换 | Switch、Win/Loss、取消访谈 | 全体用户满意度 |
| 测试方案理解 | 概念测试、原型测试 | 问题已经成立 |

决策同时需要“为什么”和“有多少”时使用 Mixed Methods。

## 3. Sampling

按行为、场景、阶段和风险招募，不只按人口属性。必要时包含失败者、流失用户、非用户、输单和极端样本。记录来源、筛选与 Screen-out 理由，不把方便样本外推到目标市场。

## 4. 执行

- 围绕最近一次真实事件提问。
- 追问顺序、频率、替代方案、后果、投入和切换触发。
- Problem evidence 与 Concept reaction 分开记录。
- 可用性测试预先定义任务、成功、错误严重度和主持人介入规则。
- 原话可解释机制，不可替代普遍性证据。

## 5. Synthesis

证据表至少包含 Participant/Segment、Observation、Interpretation、Disconfirming evidence、Confidence、Decision implication。聚类机制，不做关键词投票。

最终区分：

1. Finding：观察到什么。
2. Insight：为什么可能发生。
3. Implication：哪个决定因此改变。
4. Limitation：本研究不能证明什么。
5. Next evidence：最低成本的下一步证据。

## 6. Repository 与隐私

用稳定标签连接原始证据、Insight、产品决定和后续结果。最小化个人信息；录音、AI 转写与二次用途需要适当同意；敏感字段脱敏；未经授权不推断受保护属性。

## Quality Gate

- 研究问题映射到待决策事项。
- 方法与样本能回答该问题。
- 问题不诱导，不要求用户预测遥远未来。
- Observation、Interpretation、Recommendation 分离。
- 反例、局限和隐私处理可见。
- 结论不超过方法和样本能力。
