# Foundations

## 1. 四类产品风险

所有重大需求至少检查：
- **Value**：用户是否真的在乎？
- **Usability**：用户是否能顺利使用？
- **Feasibility**：技术是否能在约束内实现？
- **Viability**：商业、合规、运营是否成立？

## 2. 证据强度

不使用固定样本数作为通用门槛。按风险校准：
- 低成本、可逆实验：轻量证据即可，重点是快速学习。
- 中等成本功能：用户行为证据 + 访谈/工单/销售信号 + 技术可行性。
- 高成本、不可逆或高风险功能：至少两个独立证据源，并在上线前设置停止条件和人工兜底。

## 3. 事实标签

统一使用：
- `[事实]` 已有明确来源。
- `[假设]` 合理但未验证。
- `[待验证]` 对决策重要且必须补证据。
- `[风险]` 可能造成价值、成本、安全或进度损失。

## 4. 可逆性原则

优先设计可回退决策：小流量、Feature Flag、人工兜底、可降级模型、可关闭 Agent 权限。
