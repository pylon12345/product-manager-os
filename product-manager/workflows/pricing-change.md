# Workflow: Pricing Change

1. 建立 Monetization Thesis：Segment、Buyer、Value、Objective。
2. 分析 Usage、Retention、Discount、Win/Loss、Cost-to-serve。
3. 比较 Value metric 与 Packaging 选项，包括维持现状。
4. 建立 Downside / Base / Upside 财务模型和敏感性分析。
5. 用真实 Offer、Holdout 或可逆实验验证购买行为。
6. 设计 Grandfathering、迁移、沟通、例外授权和销售激励。
7. 定义 Conversion、Churn、Downgrade、Expansion、Margin 护栏。
8. 分批推出，按预设阈值继续、暂停或回滚。
9. 将结果和偏差写入 Decision Log / Retro。
