# AI Product Manager OS

AI Product Manager OS v1.1.0 的开源仓库，包含 Product Manager Skill 源码、模板、工作流、测试与专业指南。此版新增从已有代码/产品仓库反推现状、能力与下一步拆解的模式。示例案例已匿名化；运行时网页快照、知识库备份、客户资料、项目私有记录和本机配置不在仓库中。

- [产品与运营指南](PRODUCT_MANAGER_OS_GUIDE.md)
- [Skill 入口](product-manager/SKILL.md)
- [安装说明](product-manager/INSTALL.md)
- [版本记录](product-manager/CHANGELOG.md)

从 [GitHub 仓库](https://github.com/pylon12345/product-manager-os) 克隆或下载后，在仓库根目录运行 `python product-manager/validate.py` 检查包结构；复制安装方法见安装说明。知识库脚本需要 Python 3.10 或更新版本。

将 `product-manager/` 作为一个完整的 Skill 目录安装。安装 Skill 不会启动后台抓取；定期知识更新需要单独授权和调度。项目以 [Apache License 2.0](LICENSE) 开源；使用与再分发请遵守许可证及第三方内容的原有权利。
